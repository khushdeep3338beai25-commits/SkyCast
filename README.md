# 🌤️ SkyCast

SkyCast is a modern weather application built with Node.js, Express, EJS, HTML, CSS, and JavaScript.


## Technologies Used

- Node.js
- Express.js
- EJS
- HTML5
- CSS3
- JavaScript
- OpenWeather API

## Installation

```bash
npm install
npm start
```

Open:

```
http://localhost:3001
```
